# Frontend Architecture Guidelines (React 19 & TypeScript)

This document establishes mandatory conventions for all frontend code in **Project: Overclock**.
It refines the accepted ADRs ([0002](../adr/0002-technology-stack-and-modular-monolith.md), [0004](../adr/0004-runtime-model-validation-with-zod.md)) and the contract pipeline in [ADR 0007](../adr/0007-api-contract-pipeline-orval-and-zod.md).

---

## 1. Directory Structure

```
frontend/
├── openapi/overclock.json          # GENERATED by the backend build (committed, never edited)
├── orval.config.ts
├── src/
│   ├── app/                        # Router, App root, global providers
│   ├── features/
│   │   ├── auth/
│   │   ├── game/
│   │   │   ├── components/         # TerminalScreen, CardHand, CapacitorDial
│   │   │   ├── hooks/              # useGameRoom, useTurnTimer, useGameAudio
│   │   │   ├── stores/             # useGameStore.ts (Zustand)
│   │   │   └── schemas/            # Hand-written Zod schemas for SignalR events (only allowed place)
│   │   ├── inventory/
│   │   └── leaderboard/
│   └── shared/
│       ├── api/
│       │   ├── generated/          # GENERATED by Orval — DO NOT EDIT
│       │   │   ├── endpoints/      # TanStack Query hooks + TS types
│       │   │   └── zod/            # Zod schemas for REST payloads
│       │   └── http-client.ts      # Orval mutator (base URL, auth header) — the only place allowed to use fetch/axios
│       ├── realtime/               # SignalR connection manager (reconnect, token from validated sessionStorage)
│       ├── components/             # Design system primitives (Button, Dialog, ScanlineOverlay)
│       └── lib/                    # Utilities, Howler audio engine
```

Features never import from other features; shared code goes to `shared/`.

## 2. REST Contracts — generated, never hand-written

* Source of truth: the backend OpenAPI document. After any endpoint/DTO change run:
  ```bash
  npm run codegen:api
  ```
* `orval.config.ts` (reference):
  ```typescript
  import { defineConfig } from 'orval';

  export default defineConfig({
    overclock: {
      input: './openapi/overclock.json',
      output: {
        mode: 'tags-split',
        target: './src/shared/api/generated/endpoints',
        client: 'react-query',
        override: { mutator: { path: './src/shared/api/http-client.ts', name: 'httpClient' } },
      },
    },
    overclockZod: {
      input: './openapi/overclock.json',
      output: { mode: 'tags-split', target: './src/shared/api/generated/zod', client: 'zod' },
    },
  });
  ```
* Components use generated hooks only:
  ```tsx
  export function InventoryList() {
    const { data, isLoading, error } = useGetPlayerInventory();
    if (isLoading) return <CyberSpinner />;
    if (error) return <ErrorTerminal message={error.message} />;
    return <InventoryGrid items={data.items} />;
  }
  ```

## 3. SignalR — runtime validation with Zod (ADR 0004)

* SignalR payloads are untyped JSON: **never** `payload as SomeEvent`; always `safeParse`.
* Schemas live in `features/<feature>/schemas/`, are created once at module scope, and mirror the C# records in `Overclock.Modules.<Module>.Contracts`.
* Each schema has a Vitest test that parses the backend-generated fixture in `tests/contracts/signalr/<Event>.json` (ADR 0007).

```typescript
// features/game/schemas/gameEvents.ts
export const TraceCalledEventSchema = z.object({
  type: z.literal('TraceCalled'),
  callerId: z.uuid(),
  revealedCards: z.array(CardSchema),
  bluffDetected: z.boolean(),
});
export type TraceCalledEvent = z.infer<typeof TraceCalledEventSchema>;

// shared/realtime/registerGameHandlers.ts
connection.on('TraceCalled', (raw: unknown) => {
  const parsed = TraceCalledEventSchema.safeParse(raw);
  if (!parsed.success) {
    reportContractViolation('TraceCalled', parsed.error);
    return;
  }
  useGameStore.getState().applyTraceCalled(parsed.data);
});
```

## 4. State Management

* **Zustand (`useGameStore`)** — ephemeral real-time state: room, hand, turn timer, capacitor meter. Split into slices (`createRoomSlice`, `createTurnSlice`). Components select narrow slices; they never hold game state in `useState`.
* **TanStack Query** — server state over REST (profile, inventory, match history). Never copy query data into Zustand.

## 5. Mechanical enforcement (ESLint)

These rules turn the constraints above into build failures (`npm run lint` runs in `verify.sh`):

```javascript
// eslint.config.js (excerpt)
export default [
  {
    files: ['src/**/*.{ts,tsx}'],
    ignores: ['src/shared/api/**'],
    rules: {
      'no-restricted-imports': ['error', {
        paths: [{ name: 'axios', message: 'Use generated TanStack Query hooks (ADR 0007).' }],
        patterns: [{ group: ['**/features/*/**'], message: 'Features must not import other features.' }],
      }],
      'no-restricted-globals': ['error', { name: 'fetch', message: 'Use generated TanStack Query hooks (ADR 0007).' }],
      'no-restricted-syntax': ['error', {
        selector: "CallExpression[callee.property.name='on'] TSAsExpression",
        message: 'Validate SignalR payloads with Zod safeParse instead of casting (ADR 0004).',
      }],
      '@typescript-eslint/no-explicit-any': 'error',
      '@typescript-eslint/ban-ts-comment': 'error',
    },
  },
  { ignores: ['src/shared/api/generated/**'] },
];
```

Required `package.json` scripts (checked by `verify.sh`): `lint`, `typecheck` (`tsc -b --noEmit`), `test` (Vitest), `codegen:api` (Orval).

## 6. UI & Styling

* Tailwind CSS with project design tokens: phosphor amber/green text on near-black (`bg-zinc-950`), `font-mono`, CRT scanline overlay.
* Components < 150 lines; extract logic into hooks (`useTurnTimer`, `useBluffResolver`).
