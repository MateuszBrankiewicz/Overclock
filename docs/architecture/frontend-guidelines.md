# Frontend Architecture Guidelines (React 19 & TypeScript)

This document establishes mandatory conventions for all frontend code in **Project: Overclock**.
It refines the accepted ADRs ([0002](../adr/0002-technology-stack-and-modular-monolith.md), [0004](../adr/0004-runtime-model-validation-with-zod.md)) and the contract pipeline in [ADR 0007](../adr/0007-api-contract-pipeline-orval-and-zod.md).

---

## 1. Directory Structure

```
frontend/
├── openapi/overclock.json          # GENERATED by the backend build (committed, never edited)
├── orval.config.ts
├── src/
│   ├── main.tsx
│   ├── app/                        # App shell: view composition, global providers, web chrome
│   ├── features/
│   │   └── game/
│   │       ├── index.ts            # Public API — the ONLY entry point other layers (app/) import
│   │       ├── components/         # React components; subfolders per area (arena3d/, showdown/, …)
│   │       ├── hooks/              # UI hooks (useCountdown, useDebugTerminal, useTablePhase, …)
│   │       ├── session/            # Realtime session: shared connection, event handlers, hub commands
│   │       ├── stores/             # Zustand stores; slices/ wire state, reducers/ hold pure transitions
│   │       ├── schemas/            # Hand-written Zod schemas for SignalR events (only allowed place)
│   │       └── utils/              # Pure feature helpers (formatting, timing, catalogs) — no React
│   └── shared/
│       ├── api/
│       │   ├── generated/          # GENERATED by Orval — DO NOT EDIT
│       │   │   ├── endpoints/      # TanStack Query hooks + TS types
│       │   │   └── zod/            # Zod schemas for REST payloads
│       │   └── http-client.ts      # Orval mutator (base URL, auth header) — the only place allowed to use fetch/axios
│       ├── domain/                 # Cross-cutting domain types needed by shared code (e.g. CharacterId)
│       ├── realtime/               # SignalR connection manager (reconnect, Zod-validated `on`, session storage)
│       ├── i18n/                   # Translations store; locales/{pl,en}.ts, types.ts
│       ├── ui/                     # Design system primitives (HudButton, HudPanel, HudBadge)
│       ├── theme/                  # Design tokens (protocol colours)
│       └── lib/                    # Utilities, Web Audio API engine (ADR 0014), motion, haptics, WebGL probe
```

Dependency direction (enforced by ESLint, see §5):

* `app/` → `features/<f>` (through `index.ts` only) → `shared/`.
* Features never import from other features; shared code goes to `shared/`.
* `shared/` never imports from `features/`. If shared code needs a feature concept, move the type to `shared/domain/`.
* Inside a feature, `hooks/`, `session/`, `stores/`, `utils/` and `schemas/` never import from `components/`.

## 2. REST Contracts — generated, never hand-written

* Source of truth: the backend OpenAPI document. After any endpoint/DTO change run:
  ```bash
  npm run codegen:api
  ```
* `orval.config.ts` (reference):
  ```typescript
  import { defineConfig } from 'orval';

  export default defineConfig({
    overclock: {
      input: './openapi/overclock.json',
      output: {
        mode: 'tags-split',
        target: './src/shared/api/generated/endpoints',
        client: 'react-query',
        override: { mutator: { path: './src/shared/api/http-client.ts', name: 'httpClient' } },
      },
    },
    overclockZod: {
      input: './openapi/overclock.json',
      output: { mode: 'tags-split', target: './src/shared/api/generated/zod', client: 'zod' },
    },
  });
  ```
* Components use generated hooks only:
  ```tsx
  export function InventoryList() {
    const { data, isLoading, error } = useGetPlayerInventory();
    if (isLoading) return <CyberSpinner />;
    if (error) return <ErrorTerminal message={error.message} />;
    return <InventoryGrid items={data.items} />;
  }
  ```

## 3. SignalR — runtime validation with Zod (ADR 0004)

* SignalR payloads are untyped JSON: **never** `payload as SomeEvent`; always `safeParse`.
* Schemas live in `features/<feature>/schemas/`, are created once at module scope, and mirror the C# records in `Overclock.Modules.<Module>.Contracts`.
* Each schema has a Vitest test that parses the backend-generated fixture in `tests/contracts/signalr/<Event>.json` (ADR 0007).

```typescript
// features/game/schemas/gameEvents.ts
export const TraceCalledEventSchema = z.object({
  type: z.literal('TraceCalled'),
  callerId: z.uuid(),
  revealedCards: z.array(CardSchema),
  bluffDetected: z.boolean(),
});
export type TraceCalledEvent = z.infer<typeof TraceCalledEventSchema>;

// features/game/session/registerGameHandlers.ts
// GameConnectionManager.on() runs safeParse and reports contract violations;
// the handler only ever receives validated data.
conn.on('TraceCalled', TraceResolutionSchema, (resolution) => {
  useGameStore.getState().applyTraceResolution(resolution);
  recordGameEvent({ kind: 'TraceCalled', event: resolution });
});
```

## 4. State Management

* **Zustand (`useGameStore`)** — ephemeral real-time state: room, hand, turn timer, capacitor meter. Split into slices (`createRoomSlice`, `createTurnSlice`); the event → state transitions are pure functions in `stores/reducers/`, unit-tested without React. Components select narrow slices; they never hold game state in `useState` (local, purely presentational UI state such as an open menu is fine).
* **`useUiStore`** — client-only UI state shared across components: connection status, toasts, event feed, invite join, rules modal.
* **Realtime session** — server events are registered **once** for the whole app (`retainGameHandlers`, reference-counted), no matter how many components mount `useGameSession`. Hub commands are plain async functions in `session/sessionCommands.ts`.
* **TanStack Query** — server state over REST (profile, inventory, match history). Never copy query data into Zustand.

## 5. Mechanical enforcement (ESLint)

These rules turn the constraints above into build failures (`npm run lint` runs in `verify.sh`):

```javascript
// eslint.config.js (excerpt)
'no-restricted-imports': ['error', {
  paths: [{ name: 'axios', message: 'Use generated TanStack Query hooks (ADR 0007).' }],
  patterns: [{ group: ['**/features/*/**', '!./**'], message: 'Features must not import other features.' }],
}],
'no-restricted-globals': ['error', { name: 'fetch', message: 'Use generated TanStack Query hooks (ADR 0007).' }],
'@typescript-eslint/no-explicit-any': 'error',

// src/shared/**: shared code must not import from features
// src/features/*/{hooks,session,stores,utils,schemas}/**: must not import components
// src/shared/api/**, src/shared/lib/**: may use fetch (http-client, audio assets)
```

`npm run lint` runs in `verify.sh`.

Required `package.json` scripts (checked by `verify.sh`): `lint`, `typecheck` (`tsc -b --noEmit`), `test` (Vitest), `codegen:api` (Orval).

## 6. UI & Styling

* Tailwind CSS with project design tokens: phosphor amber/green text on near-black (`bg-zinc-950`), `font-mono`, CRT scanline overlay.
* Components < 150 lines; extract logic into hooks (`useTurnTimer`, `useShowdownSequence`).
* Exception: three.js scene files in `components/arena3d/` (procedural geometry, materials, rigs) may be longer when splitting would only scatter one mesh across files. Their state and timing logic still belongs in hooks or pure helpers.
